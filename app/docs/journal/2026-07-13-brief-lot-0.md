## Périmètre — 5 chantiers

### 1. `detectBranlee(round)` — NEUF *(`domain/`, ex. `branlee.ts` ou dans `scoring.ts`)*
- Signature : `detectBranlee(round: Round): null | 'petite' | 'grosse'`.
- Se calcule sur le **total distribué de la manche** (somme des scores de manche
  des 4 joueurs) : **≥ 45 → `'grosse'`** ; sinon **≥ 30 → `'petite'`** ; sinon
  `null`. **Bornes inclusives** (la grosse absorbe la petite).
- Retourne **seulement la sévérité** — pas le donneur (le donneur = `roundWinner`,
  géré côté appelant).
- Source : `logique-comptage` §Détection de la branlée · `cas-reference-score`
  §branlée.

### 2. `stats.ts` — miroirs indépendants [R]
- **Décroiser les pôles** : ✌️ (champion) sur les **🏆 seuls**, 🐌 (looser) sur les
  **💩 seuls**. **Retirer** les départages croisés actuels (✌️ par « moins de 💩 »,
  🐌 par « moins de 🏆 ») — sinon le **monde étrange** (même joueur les 2 trônes)
  reste interdit.
- Départages : **✌️** = 🏆 → ⭐️ manches → **branlées données** → **tenant reste**
  (par rejeu) · **🐌** = 💩 → 💥 manches perdues → **branlées prises** → **tenant
  reste**.
- **Portée : soirée → gang** — filtrer le vrac sur les **4 mêmes prénoms triés**.
- Ajouter les **compteurs branlées** : donnée = +1 au donneur (`roundWinner` de la
  manche où `detectBranlee` ≠ null) ; prises par déduction.
- Source : `logique-comptage` §titres · `specs-stats` · `cas-reference-score`
  §titres miroirs.

### 3. `model.ts` — 3 issues + gofCount [R]
- `GameStatus` += `'annulee'` → `'en-cours' | 'annulee' | 'terminee'`.
- `Game` + `gofCount: number` (défaut `0`) ; idem `GameArchive`.
- `GameArchive` — retirer « ou interrompue » du commentaire : **seule la terminée
  est archivée**.
- `Session` reste **dérivée** (date + lieu optionnel) ; « session » = **nom interne
  seulement**, jamais dans le copy visible.
- Source : `modele-donnees`.

### 4. `gameStore.ts` — 3 issues, annuler ≠ archiver [R]
- **Supprimer la branche qui archive une partie interrompue** (`resetGame`,
  ~l.80-84 actuel : `if (rounds.length > 0 && status !== 'terminee')`). **Annuler
  une partie = la jeter** (`clearGame`), **jamais l'archiver au vrac**.
- Exposer l'annulation (statut `'annulee'` → clear). *Le confirm à l'accueil est
  lot 3a ; ici, seulement le comportement store.*
- **Pause/reprise** : l'en-cours persiste déjà (`saveGame` à chaque manche) —
  garder tel quel.
- `gofCount` : champ porté sur le `Game`, coulé dans l'archive. *L'incrément (tap
  Gong) est lot 4 — ici, le champ + défaut `0` suffisent.*

### 5. `soireeStorage.ts` — LE VRAC, stockage neuf [R] *(N1 — contrat spec'd ici)*

**Repart à zéro** (nouveau build, **rien à migrer**). Contrat :

- **Clé** : `gof:vrac` (neuve). L'ancienne `gof:soiree` n'est **plus lue ni
  écrite**.
- **Forme stockée** : `{ schemaVersion: 1, parties: GameArchive[] }` — un tableau
  **à plat** de toutes les `GameArchive` **terminées**, inter-sessions.
- **`schemaVersion`** : entier, démarre à `1`. Au load : absent/null → vrac vide
  `{ schemaVersion: 1, parties: [] }`. (Pas de legacy — build neuf.)
- **Fonctions** : `loadVrac()` · `saveVrac(vrac)` · `appendToVrac(vrac, archive)`
  (ajoute une terminée). La partie **en cours** reste sous `gof:game` (inchangé).
- **Sessions dérivées, pas stockées** — groupées à la volée par
  `soireeDate(archivedAt)` (tolérance nuit < 5h conservée). Le **gang** dérivé =
  filtre sur les 4 prénoms triés.
- **Bascule** : une partie rejoint le vrac au game-over (terminée, scellée).
  Annulée : **jamais**.
- Source : `modele-donnees` §Persistance · `specs-stats` §frontière P1.
