# Brief — Lot 2 · la voix (les annonces sur le plateau)

> **Pour l'instance d'intégration.** Ton monde = ce fichier + les specs sources
> citées (elles font foi). Le **domaine (lot 0)** et la **scène (lot 1)** sont
> faits et scellés — tu **ajoutes la voix par-dessus**, tu ne réécris ni la
> logique ni le Round. À la fin : un diff + les tests + une note de jouabilité,
> puis handoff propre.

## Intention

Donner à GANG sa **voix qui claque**. Le principe qui commande tout :
**rareté = intensité** — le fréquent reste discret, le rare **arrête la table**.
Les annonces vivent **sur le plateau** (surdominants), jamais dans la zone du bas.
**Un seul surdominant à la fois** : le plus fort claque, le cartouche absorbe le
reste (pas de cascade). Lot 2 = le **comportement** + un rendu **ossature** ; le
rendu fin (easing, particules, assets sonores définitifs) est **parqué** (lot 4).

## Périmètre — ce qui est DEDANS

### 1. `Annonce.tsx` [N] — la couche surdominante (sur le plateau)
Un overlay qui s'affiche **au-dessus du plateau** (le plateau reste, il est
éclaboussé/figé selon le cas). Porte les 4 intensités de l'échelle (§2). Monté
au-dessus de `plateauZone` du Round.

### 2. L'échelle — rareté = intensité *(reshape §battement ④)*
| événement | intensité | rendu (ossature) |
|---|---|---|
| **manche gagnée** (chaque manche) | discret | la pill du gagnant **respire** (pulse léger) |
| **passe devant** (un joueur double un autre au classement) | flash léger | un flash bref sur le plateau |
| **branlée** (`detectBranlee` ≠ null) | **cérémonie** (§3) | plateau **figé**, surdominant, 2 sorties |
| **fin de partie** (100, `isGameOver`) | **le final** (§4) | plein plateau, miroir gloire/💩 |

*Le gate ne porte que sur la **cérémonie** et le **final** (§3, §4). Le discret et
le flash sont l'ossature de l'échelle — structure oui, easing léché non.*

### 3. La cérémonie branlée *(le cœur du lot — reshape §cérémonie, branlee.md)*
Au moment du calcul (« = »), **si** `detectBranlee({ cardCounts }) ≠ null` :
- le plateau se **fige** (surdominant, projecteur sur la manche) ;
- **copy** : « **petite / grosse branlée de {prénom}** ! » (le donneur = `roundWinner`) ;
- **dialogue à 2 sorties** :
  - **corriger** — retour à la saisie, **rien n'est commité** (le crayon,
    réversible ; on garde les chiffres tapés pour éditer) ;
  - **graver** — **commit** (`addRound`), scellé, irréversible (le gravé). *« On
    ne grave qu'après avoir choisi de graver » — pas de fausse branlée par accident.*
- **Change le flux du Round** : aujourd'hui `onValidate` fait `addRound`
  directement. Désormais : si branlée → cérémonie (differe `addRound` jusqu'à
  **graver**) ; sinon → `addRound` direct (comme lot 1). **La branlée est la
  SEULE manche qui passe par la cérémonie.**
- Le **mot du bouton graver** est provisoire (copy-deck) ; **la marque encoche
  `/` `//` ne se rend PAS ici** — elle vit dans la feuille/stèle (lot 3b). Ici,
  c'est du **texte**.

### 4. Le final *(reshape §fin de partie — « forme validée »)*
Quand un joueur touche 100 (`isGameOver`) → **remplace la fin « nue » du lot 1** :
- plein plateau, **miroir côte à côte** : le **vainqueur** (`determineWinner`,
  cumul le plus bas) **en gloire** + le **dernier** (`gameLoser`) au **💩** ;
- **⚠️ l'asymétrie du son = exigence sémantique (N2), pas du polish** : la
  **gloire prend le son** (un cue/rugissement — **asset placeholder autorisé** :
  réutilise un son existant `gofSound` si pas d'asset dédié), la **honte prend le
  SILENCE** (aucun son). *C'est la colonne de GANG rendue audible — bâtis
  l'asymétrie même si l'asset final viendra plus tard.*
- puis **une porte** : **« on rejoue ? »** (→ `resetGame(true)`, même roster). *Les
  portes « consulter » (→ stèle) et le scellé de la feuille = lot 3b ; ici, « on
  rejoue ? » suffit (garde « nouveaux joueurs » du lot 1 si utile).*

## Definition of done = LA GATE

**Une branlée saisie déclenche la cérémonie** (plateau figé, copy petite/grosse,
2 sorties — *corriger* ne grave rien, *graver* commit la manche). **Une partie
finie déclenche le final** (miroir gloire/💩 + **son côté gloire, silence côté
honte**), puis « on rejoue ? ». `tsc` clean. **Les 83 tests du lot 0 restent
verts** (tu ne touches pas au domaine).

*(Lot UI/comportement : preuve surtout **manuelle sur device**. Ajoute des tests
de composant/smoke si peu coûteux ; ne casse aucun test existant.)*

## Rendu

Le diff complet + `npm test` (les verts) + une **note de jouabilité** : ce que tu
as déclenché (une branlée → cérémonie → corriger ET graver ; une partie finie →
final avec/sans son). Puis tu **t'arrêtes** — handoff propre. Porte ② à la
supervision.
